# 🎬 Birthday Video & Wishes Generator

An interactive, responsive web application that allows users to create customized Birthday Videos and Cards with personal photos, custom Hindi Shayaris, and background instrumental music.

## ✨ Features

* 📸 **Photo Upload:** Upload any image with a clean, high-definition layout.
* ✍️ **Custom Shayari & Wishes:** Choose from 10+ built-in Hindi birthday shayaris or write your own custom message.
* 🎹 **Instrumental & Piano Tunes:** Select from 10 different relaxing piano, guitar, and orchestral birthday tunes.
* 🎈 **Festive Animations:** Dynamic floating balloons and gradient party themes powered by HTML5 Canvas.
* 📲 **Instant Video Recording:** Download the generated video/animation directly to your device with a single click.

## 🛠️ Tech Stack

* **HTML5** & **CSS3** (Responsive Glassmorphism UI)
* **JavaScript** (Vanilla JS, Canvas API, MediaRecorder API)
